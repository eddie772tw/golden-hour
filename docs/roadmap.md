# 分支開發方向

多人對戰下一階段以斷外網熱點及玩家自營專服為目標。配對方式、可攜帳號、進房驗證、專服啟動腳本與跨機驗收見[自營多人對戰與可攜帳號設計](self-hosted-multiplayer.md)。

| 方向 | 下一個可交付的改動 | 驗收方式 |
| --- | --- | --- |
| 強化反作弊措施 | 建立含門窗、交疊牆體、上下樓層與快速探頭的可見性回放。以伺服器事件分析兩個競技身分互刷的情形。 | 同場兩個觀察者的快照與射擊事件各自符合可見性；可見角色的模型及記分板可及時恢復。以不同規模的房間驗證互刷候選條件，報告可疑事件與正常對局的重疊比例，先保留稽核紀錄。 |
| 提升連線穩定度 | 建立可重播的時延、抖動、丟包與短暫中斷測試，對照單房與多房。可分別試驗 AimArena 中的伺服器時間預算與房間排程。 | 記錄往返時間、快照缺口、輸入確認延遲、重連時間與模擬 tick 耗時的中位數和第 95 百分位。測試席位保留期間與逾時兩種情境；恢復當局身分後，戰績不得重複入帳。 |
| 擴充遊戲內容 | 先做一把可在訓練與對戰使用的新武器，串接模型／持握點、武器數值、伺服器換裝條件、槍械工坊和五語說明。 | 訓練可裝備射擊；對戰端可驗證射速、彈藥、命中與解鎖；現有 KR-7、VESPER、M12 門檻回歸通過。新增素材要有可追溯的來源與發行條件。 |

已建立兩個獨立客戶端經區網介面與自營專服完賽、搬移存檔及重啟還原的測試。兩台實體裝置與斷外網熱點仍需現場驗收。對外部署前還需要真正跨網路的 ICE、憑證、長時間連線、負載與競技身分驗證資料。以上三項是後續開發工作。
